# DCCCcore 4.6.2-alpha / dcccpy 0.3.0a6

> Superseded by [4.6.3-alpha](4.6.3-alpha.md), which restores ADNI FDG
> compatibility and provides a separate SCAN interface. This GitHub Release
> is scheduled for removal after replacement installation verification.

This prerelease changes the default Level 3 intensity preprocessing for
`adni-pet-core --tracer fdg` from iterative global-mean scaling to a
SCAN-inspired pons/cerebellar-vermis reference.

The binary reference combines Clinica's 6 mm eroded pons mask and AAL2 vermis
labels 9100–9170, independently resampled in physical coordinates to DCCC's
padded MNI 2 mm grid. The divisor is the mean of the highest ceil(N/2) PET
intensities in the combined reference, sampled in spatially normalized PET
and applied to the existing rigid-aligned ADNI-grid output.

Rigid alignment, motion correction, Level 1/2 exports and Aβ/tau/DAT intensity
references retain their existing behavior. This approximates SCAN's reference
normalization; it does not reproduce Berkeley's hand-drawn mask or establish
numerical agreement with SCAN's full pipeline. Existing FDG workflows should
expect changed intensity values.

See [mask provenance, licenses and rebuild instructions](../../localizer/src/assets/nii/FDG/README.md).
Custom configurations must provide `masks.fdg_pons_vermis_ref`; the two bundled
configurations include the new entry.

Versions are synchronized: core/tag `4.6.2-alpha` / `v4.6.2-alpha`, wrapper
`0.3.0a6`, and all four optional platform runtime packages `0.2.0a5`.
The runtime extras target this exact core version. Runtime wheels must be
published from completed GitHub Release assets before the wrapper is uploaded.

```sh
pip install --pre 'dcccpy[runtime]==0.3.0a6'
DCCCcore adni-pet-core --input fdg.nii.gz --output fdg_preprocessed.nii.gz --tracer fdg
```

Local validation before release: full Docker C++ build; 11 ADNI CLI tests;
2 standalone C++ reference tests; mask geometry/hash test; 52 Python package
tests passed with one opt-in TestPyPI test skipped. Cross-platform Actions
and release publication are verified separately after the release build.
