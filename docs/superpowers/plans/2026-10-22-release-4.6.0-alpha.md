# 4.6.0-alpha release plan

User authorized publishing from GitHub dev, cross-platform builds, a standalone
model Release asset, and a new dcccpy alpha using the supplied PyPI credentials.
Execute inline. Existing dev fast-forwarded to the verified segmentation work.

## Distribution contract

- DCCCcore `4.6.0-alpha`: all three AGENTS.md version files stay synchronized.
- dcccpy `0.3.0a4`; runtime extras `0.2.0a3`, each targeting core `4.6.0-alpha`.
  These versions were confirmed unused on PyPI before preparation.
- Native/Slicer archives include the segmentation model. Release also provides
  `DCCCseg-4.6.0-alpha.zip` with model, controls, provenance and checksums.
- PyPI wheels exclude `assets/models/seg`. dcccpy reuses an installed native
  bundle, otherwise downloads the standalone asset on first seg invocation,
  verifies the known model SHA-256, and caches outside site-packages.
- Honor existing auto-download opt-out and explicit `bundle=`. Expose manual
  `download_seg_model()` for offline provisioning.
- Versioned workflow_dispatch on dev builds all release platforms, packages,
  creates a prerelease/tag at the built commit, and uploads model separately.
- Keep macos-latest and a macos-15 compatibility build; macos-14 is approaching
  retirement (upstream runner-images issue 13518).
- Never log credentials. Do not publish incomplete or oversized wheels. All
  build/test/package validation and PyPI uploads run in Docker.

## First CI failure and retry

All five platform builds compiled successfully. The only test failures were
the three `test_seg_oblique_native_geometry_and_labels` cases: their independent
NiBabel resampling reference needs optional SciPy, which the workflow did not
install. The Linux/macOS jobs reported 150 passed, 8 skipped, 3 failed; Windows
reported 152 passed, 6 skipped, 3 failed. Release creation was correctly skipped.

Reproduced the same three SciPy `TripWireError` failures in a clean Docker venv
against the installed `4.6.0-alpha` executable. Installing SciPy alone made all
three pass (20.22 seconds). Added SciPy to CI test dependencies on all platforms,
without changing native/model code or weakening/skipping geometry assertions.
Docker actionlint and wrapper tests (42 passed, 1 skipped) passed. The complete
native test suite in that clean venv passed: 153 passed, 8 skipped in 619.19 s.
